Remarks

The natural key is Site + Kind + Name; the three never change (§36.3 rule 4) and so are never drift. Every other member is a field, reconciled by §27.6 rule 3: a null (unstated) member is silent, and on an Update is carried from the read, because the replacement body would otherwise clear it.

Judged on the read. Every stated member is compared with the value the read returns. FilterIds is compared as a set: the same names in another order are NoChange, a list that repeats a name is refused at PlanAsync with zero wire calls, and when the SDK writes the segment it sends the names in the order stated here.
