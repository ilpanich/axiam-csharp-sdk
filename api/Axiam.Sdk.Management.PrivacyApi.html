DownloadExportAsync(Guid, CancellationToken)

Single-use download of the GDPR export blob (D-13). Looks up the job by SHA-256(token), verifies it is ready and not expired/used, decrypts the blob, marks it as downloaded, and deletes the record. Requires authentication (self or admin with gdpr:export).
