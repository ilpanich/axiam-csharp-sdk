Remarks

Obtained from client.Management. Each accessor returns a namespace handle, which is a view over the same session — acquiring one performs no I/O (§27.2 rule 1).

The namespaces are grouped behind this one accessor rather than added to AxiamClient directly: §27.2's own argument for handles is that a flat surface of 147 methods buries the twenty a given caller needs, and hanging 24 more members off AxiamClient would do to it exactly what the handles exist to prevent.
