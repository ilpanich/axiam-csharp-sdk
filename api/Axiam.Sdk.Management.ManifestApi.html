Remarks

Two operations, and the difference between them is the whole design. PlanAsync(ManagementManifest, CancellationToken) issues reads and nothing else, so it can be run against production to find out what an ApplyAsync(ManagementManifest, CancellationToken) would do. ApplyAsync(ManagementManifest, CancellationToken) performs the writes, stops at the first failure, and does not roll back.

A view over the management API, not a connection: constructing one performs no I/O (§27.2 rule 1).
