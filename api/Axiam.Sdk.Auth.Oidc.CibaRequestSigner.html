The key and algorithm for the signed request form (§33.2, CIBA Core §7.1.1). Both are the caller's: there is no default for either, and the SDK signs under exactly the algorithm given — the client's registered backchannel_authentication_request_signing_alg.

Remarks

The key is key material (§33.5): ToString() names the algorithm and the kid, never the key, and no accessor returns it. A key that cannot sign under the algorithm is refused at construction by signing a probe.
