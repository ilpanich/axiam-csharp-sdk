Remarks

By default this class holds NO local cache of any authorization decision — every call hits the server fresh, because a client-side cache can silently diverge from the server's live decision. CONTRACT.md §11.2 rule 6 makes that the default and §17 carves out the single opt-in exception: a TTL-bounded Axiam.Sdk.Core.DecisionMemo, off unless DecisionMemoTtl is set, whose cost (read-your-own-writes is not guaranteed, in both directions) is documented on that option.

AXIAM's RBAC engine is default-deny with deny-override: an explicit effect: deny grant refuses regardless of what else allows it, at any depth of the hierarchy. (This remark said "additive-only, allow-wins" until B1 shipped deny-override and closed SEC-040.)

Remarks

Exists because CheckAccessAsync(string, Guid, string?, Guid?, CancellationToken) returns a bare bool that predates that field and cannot carry it without a breaking signature change. The distinction it surfaces is not cosmetic: no_grant means "ask an admin for access", denied_by_rule means "an admin has already decided", and an application that cannot tell them apart sends users to raise tickets that will be refused.
