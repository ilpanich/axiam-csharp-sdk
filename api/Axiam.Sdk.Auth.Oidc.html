Namespace Axiam.Sdk.Auth.Oidc

Classes

AuthorizationRequest

The result of OidcBegin(OidcConfiguration, OidcBeginParams) — everything the caller needs to start an authorization-code + PKCE login (CONTRACT.md §12.1).

IdTokenClaims

The decoded, ALREADY-VALIDATED ID-token claim set carried by IdClaims (CONTRACT.md §12.1).

IdTokenFailureReasons

The seven CONTRACT.md §12.3 rule 3 / §12.4 stable, machine-readable ID-token validation failure reason codes, carried on the resulting Reason. Exact wire spelling — used verbatim, never translated or localized.

IntrospectParams

Arguments to IntrospectAsync(IntrospectParams, CancellationToken) (RFC 7662). Requires confidential-client credentials (§12.1 note 4).

IntrospectionResult

The RFC 7662 introspection result (wire schema IntrospectionResponse). Only Active is guaranteed; the server omits the metadata fields for an inactive token (all null).

LoginClientCredentialsParams

Arguments to LoginClientCredentialsAsync(LoginClientCredentialsParams, CancellationToken) (grant_type=client_credentials).

MemoryOidcStateStore

An in-memory reference implementation of IOidcStateStore (CONTRACT.md §12.3 rule 1): per-instance (never process-global/static), single-use, TTL-bounded, backed by a ConcurrentDictionary<TKey, TValue>.

OidcBeginParams

Arguments to OidcBegin(OidcConfiguration, OidcBeginParams) — a pure local computation, no network I/O. client_id comes from the client's own configuration (OidcClientId), not a per-call argument (§12 T1 reference judgment call 21).

OidcConfiguration

The OIDC Discovery 1.0 metadata document served by GET /.well-known/openid-configuration (wire schema OidcDiscoveryDocument, CONTRACT.md §12.1). Every field is required by the server's schema, so this record keeps the wire's exact snake_case property names — it IS a protocol document, not an SDK-shaped result.

OidcExchangeParams

Arguments to OidcExchangeAsync(OidcExchangeParams, CancellationToken) (grant_type=authorization_code).

OidcRefreshParams

Arguments to OidcRefreshAsync(OidcRefreshParams, CancellationToken) (grant_type=refresh_token).

OidcStateEntry

The tuple an IOidcStateStore holds for one in-flight login.

OidcTokenSet

A token set returned by the OAuth2 token endpoint (wire schema TokenResponse), returned by OidcExchangeAsync(OidcExchangeParams, CancellationToken), OidcRefreshAsync(OidcRefreshParams, CancellationToken) and LoginClientCredentialsAsync(LoginClientCredentialsParams, CancellationToken).

RevokeParams

Arguments to RevokeAsync(RevokeParams, CancellationToken) (RFC 7009). Requires confidential-client credentials (§12.1 note 4).

SsoCompleteParams

Arguments to SsoCompleteAsync(SsoCompleteParams, CancellationToken) (POST /api/v1/auth/federation/oidc/callback).

SsoCompleteResult

The result of SsoCompleteAsync(SsoCompleteParams, CancellationToken) (wire schema SsoLoginSuccessResponse). Carries NO token material — the session arrives as Set-Cookie, so the §4 cookie jar (already owned by every AxiamClient) is what actually captures it (§12.1 note 6).

SsoStartParams

Arguments to SsoStartAsync(SsoStartParams, CancellationToken) (POST /api/v1/auth/federation/oidc/start). One tenant form (TenantId or TenantSlug) and one org form (OrgId or OrgSlug) must be resolvable, from these properties or from the client's own construction options (CONTRACT.md §5.1).

SsoStartResult

The result of SsoStartAsync(SsoStartParams, CancellationToken) (wire schema OidcStartResponse). There is deliberately no nonce: on the federation path the nonce never leaves the server (§12.1 note 7). Round-trip State into SsoCompleteAsync(SsoCompleteParams, CancellationToken) unmodified — the server stores it single-use with a 10-minute TTL and recovers the whole login context from it.

Interfaces

IOidcStateStore

An OPTIONAL server-side store for in-flight OidcBegin state (CONTRACT.md §12.3 rule 1).
