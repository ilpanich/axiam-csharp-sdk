Remarks

DeviceCode is Sensitive<T> (§14.5): a bearer credential for the lifetime of the grant. UserCode deliberately is not — it exists to be read aloud and typed by a human, and wrapping it would defeat the one thing it is for. Neither may be logged; displaying the user code is the caller's job.
