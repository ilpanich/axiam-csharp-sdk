Remarks

The server cannot compute this — it never sees the plaintext — so any request that sets a password has to carry it: POST /api/v1/users, /auth/password/change, /auth/reset/confirm and /admin/bootstrap (§23.3 rule 11).

Neither Salt nor Verifier may be logged (§23.3 rule 12).
