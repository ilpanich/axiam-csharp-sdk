Remarks

Member names are the wire names — this type serializes to the document byte for byte. RFC 9728 defines further members; §28.2 forbids emitting them in this contract version, because a member one SDK emits and ten do not is a divergence the cross-SDK review would have to reconcile.

ScopesSupported and ResourceDocumentation are omitted, never emitted empty or null, when the caller supplied none.
