Remarks

Every member is optional and null means unchanged: the member keeps the value the stream was read with. The five members the wire lets a caller clear (Description, EndpointUrl, StatusReason, ExpectedUpdatedAt and, by their own rules, the authorization header through ClearAuthorizationHeader) are JsonNullable<T>: assign JsonNullable<string>.Null to say "none".

An assigned null is "none" (CONTRACT.md §27.11 rule 5): ExpectedUpdatedAt = JsonNullable<string>.Null leaves the expected_updated_at key out of the body and null is never sent; the update then replaces whatever is stored instead of landing only on the version that was read.
