Remarks

Expired entries are dropped lazily on SaveAsync(OidcStateEntry, CancellationToken)/ConsumeAsync(string, CancellationToken) — there is NO background timer/thread, since a library must not keep the host process alive on its own. Suitable for a single-process app and for tests. A multi-instance deployment needs a shared store (Redis, a database) — implement IOidcStateStore directly for that; nothing in this SDK assumes this type.

ConsumeAsync(string, CancellationToken)

Atomically fetches AND REMOVES the entry for state. Returns null when the state is unknown, already consumed, or expired — three cases a caller MUST treat identically (as a failed login), because distinguishing them leaks whether a state ever existed.

Remarks

Removal happens BEFORE the expiry check, so even an expired hit is removed rather than left to accumulate, and a second call can never return the same entry twice regardless of timing.
