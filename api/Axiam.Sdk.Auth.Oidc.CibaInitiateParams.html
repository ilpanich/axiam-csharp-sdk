Remarks

Exactly the members set are sent. BindingMessage and the login hint can be personal data: the SDK never logs them. login_hint_token, user_code and request_uri have no member here — AXIAM refuses each (§33.3 rule 3) — and there is no way to add an arbitrary form parameter, so a signed request can carry nothing beside request and the client's authentication.
