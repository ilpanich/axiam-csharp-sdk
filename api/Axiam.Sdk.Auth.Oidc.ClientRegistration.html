Remarks

RegistrationAccessToken and ClientSecret are Sensitive<T> (§28.12.4): ToString(), the compiler-generated record printer and System.Text.Json all render them as [SENSITIVE].

Decoding is tolerant. Every member the server sent that this type does not name — and a named member that arrived with an unexpected JSON type — is kept verbatim in Extra. That matters because an update is a full replacement: a member a read returned and an update left out is a member the server deletes. Passing a read's result (or a with-expression over it) straight to UpdateClientRegistrationAsync(string, Sensitive<string>, ClientRegistration, CancellationToken) therefore sends it back intact, jwks / jwks_uri and the CIBA backchannel_* members included.
