Parameters

OnUserCode Func<DeviceAuthorization, Task>

Invoked with the DeviceAuthorization before the first poll (§14.3 rule 2), so the caller can display the code. A Func<T, TResult> returning a Task, so a device that must await a paint or a redraw can — polling does not begin until it completes. The SDK never prints the code.

AdoptAsCredential bool

Mirrors AdoptAsCredential: this port does not implement adoption and throws NotSupportedException when it is set. §14.3 rule 4 (contract 1.7) defers to the §12.1 adoption MAY, so this SDK takes the same posture here rather than inventing a second one.
