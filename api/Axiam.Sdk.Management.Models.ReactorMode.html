[WireName("")] Unknown = 2

A value this SDK’s copy of the spec does not list.

Its wire spelling is the empty string, which no server value is: carrying an unrecognised value back into an update is refused by the server rather than silently written as a spelling it never used. Fifteen of these enums appear in request bodies, which is what makes that distinction worth having.

It is deliberately not the zero member — defaulting to it would make “the server said nothing” and “the server said something new” the same value.

Remarks

Each member carries the spelling the server uses on the wire via WireName, so the C# name can follow C# conventions without changing what is sent.

An open enum. A value this SDK’s copy of the spec does not list decodes to ReactorMode.Unknown rather than failing the response it arrived in (§27.11 rule 1) — a closed enum turns the next value the server adds into a parse error on the whole list, taking down every record on the page over one field of one of them. A switch over these members needs an Unknown arm.
