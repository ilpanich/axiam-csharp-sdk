Parameters

Allowed bool

Whether the checked action is permitted. This property alone carries the outcome — ReasonCode explains it and never contradicts it.

Reason string

The server's human-readable explanation, when it sent one.

ReasonCode string

Allowed, NoGrant or DeniedByRule.

The two refusals mean opposite things to the person on the other end. no_grant says ask an admin for access; denied_by_rule says an admin has already decided. An application that cannot tell them apart sends users to raise tickets that will be refused — which is why the contract forbids collapsing them into a bare false.

null when the server omits the field, so a newer SDK against an older server degrades rather than failing. An unrecognised value is surfaced verbatim and never changes Allowed — which is why this is a string rather than an enum.
