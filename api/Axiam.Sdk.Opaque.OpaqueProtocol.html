Remarks

There is no cryptography in this class, or anywhere in this namespace. That is deliberate and is what §23.1 requires: OPAQUE needs an oblivious PRF, hash_to_curve, expand_message_xmd, an envelope construction and a three-message AKE, and eleven independent implementations of that is eleven chances to be subtly and silently wrong. The SRP-6a this replaces was arithmetic every language can express, which is why Axiam.Sdk.Srp existed.
