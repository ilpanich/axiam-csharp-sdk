Remarks

This body REPLACES rather than patches (§27.4 rule 5): what you do not carry over from a prior read is not preserved, it is overwritten. acs_urls, display_name, entity_id are required, so forgetting one is a compile error; an optional property you leave unset is omitted from the wire, and the server then applies its default rather than keeping the stored value, except where the operation documents otherwise. Read first, with-expression the parts you mean to keep, write back.
