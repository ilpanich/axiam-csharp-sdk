Remarks

Every property is optional, so this is a SPARSE body: what you leave unset is left unchanged, and is omitted from the wire request entirely rather than sent as null (§27.4 rule 5). Naming the properties you mean to change is the whole API — there is no builder because C# object initializers already are one, and no way to accidentally send a field you did not name.
