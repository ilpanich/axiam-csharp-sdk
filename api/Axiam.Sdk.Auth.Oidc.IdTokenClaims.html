Remarks

Claim names are kept verbatim in their JWT/OIDC spelling (Iss, Sub, Aud, …) rather than C#'s usual naming conventions — they are protocol identifiers a caller cross-references against OIDC Core. Extra preserves any further claim the server sends (e.g. email, preferred_username) — the ID token's full claim set is not enumerated by openapi.json (the field is typed as an opaque string there), so SDKs MUST NOT reject unknown claims.
