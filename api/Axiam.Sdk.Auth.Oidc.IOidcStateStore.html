An OPTIONAL server-side store for in-flight OidcBegin state (CONTRACT.md §12.3 rule 1).

public interface IOidcStateStore

Remarks

Implement this to back the ASP.NET Core login/callback endpoints (MapAxiamOidcLogin) with your own storage (Redis, a database, an encrypted cookie). Two invariants are normative:

  1. Single-use: ConsumeAsync(string, CancellationToken) MUST return the entry AND delete it atomically, so a replayed callback cannot reuse a state.
  2. Expiry: an entry older than the store's TTL (10 minutes, at most — MaxTtl) MUST NOT be returned.

Methods

ConsumeAsync(string, CancellationToken)

Atomically fetches AND REMOVES the entry for state. Returns null when the state is unknown, already consumed, or expired — three cases a caller MUST treat identically (as a failed login), because distinguishing them leaks whether a state ever existed.
