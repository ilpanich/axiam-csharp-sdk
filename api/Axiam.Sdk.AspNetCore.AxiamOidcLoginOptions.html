OnSuccessAsync

Called with the validated token set once the exchange succeeds — the hook where an application establishes its OWN session (sign a cookie, write a session row, …). This class deliberately does not do this for you: what a session means is the application's decision. Receives the consumed state entry too, so ReturnTo and any other application data captured at login time is available. May be null.

public Func<HttpContext, OidcTokenSet, OidcStateEntry, CancellationToken, Task>? OnSuccessAsync { get; set; }

RedirectUri

The relying party's redirect URI — the public URL of the callback route — replayed verbatim on the token exchange (the server compares the two). Required.

Remarks

Mutable (set, not init) — mirrors AxiamOptions's existing convention: the .NET options-callback pattern (MapAxiamOidcLogin(loginPath, callbackPath, options => { … })) configures an already-constructed instance through an Action<T> delegate, so properties must be settable after construction.
