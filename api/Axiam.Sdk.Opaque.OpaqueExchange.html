Remarks

The handle is single-use: the library consumes it in Finish whether that succeeds or fails. This class takes it out of a one-shot slot, so a second Finish raises a .NET exception rather than handing a dangling pointer across the ABI.

IDisposable and a finalizer, in that order of preference: using releases an abandoned exchange deterministically, and the finalizer catches a caller who started a login and never completed it. Both go through the same one-shot slot, so neither can double-free.
